Who I Am

I'm Manjunatha H, an Embedded Systems Developer from Bengaluru, India. I hold a B.E. in Electrical & Electronics Engineering from Jain Institute of Technology, Davanagere.

My passion lives at the intersection of hardware and software — where every byte counts and every bit has a purpose. I love understanding how things work at the lowest level.

I've built real projects in C that touch file I/O, bitwise operations, binary parsing, and memory management. I've completed UART, I2C, SPI, CAN and RTOS, and put them to work in PIC18 projects like a CAN-based automotive dashboard and a Car Black Box.

I've also worked through Linux basics, Embedded Linux and Linux Internals / Kernel. I don't wait for a classroom — I pick a concept, break it down, and build something with it.

What I've Built

PROJECT_01
🚗
CAN-Based Automotive Dashboard

A 3-ECU instrument cluster on PIC18 microcontrollers exchanging live speed, gear, RPM and turn-indicator data over the CAN bus. A dedicated node renders it all on a 16x2 LCD dashboard, with turn-signal LEDs and a buzzer.

Embedded C CAN Protocol PIC18 ADC LCD
View on GitHub ↗
PROJECT_02
📦
Car Black Box (Event Data Recorder)

A PIC18-based automotive black box that timestamps every gear-shift and collision event using a DS1307 RTC and permanently logs it to external EEPROM. An on-device menu lets you view, download (over UART) and clear the logs.

Embedded C I2C UART RTC EEPROM State Machine
View on GitHub ↗
PROJECT_03
🔍
Inverted Search Engine

A high-performance search engine in C — just like how Google indexes the web. Builds an inverted index using Hash Tables & Linked Lists so keyword searches across thousands of files happen in O(1) time instead of scanning every file.

C Hash Tables Linked Lists Dynamic Memory File Handling Modular Code
View on GitHub ↗
PROJECT_04
🔐
LSB Steganography

Hides secret messages inside BMP images by replacing the Least Significant Bit of every pixel byte. Completely invisible to the human eye. Supports any file extension with full metadata encoding and decoding.

Embedded C Bitwise Ops Binary File I/O Structs CLI Args
View on GitHub ↗
PROJECT_05
📒
Address Book

Full CLI contact management system — add, search, edit, delete contacts with name, phone & email validation. Data persisted to file using File I/O. No database, no libraries — pure C from scratch.

C Structs & Arrays File Handling String Ops Modular Code
View on GitHub ↗
PROJECT_06
🎵
MP3 Tag Reader

Binary file parser that reads ID3 metadata from MP3 files — title, artist, album, year, genre. Directly seeks to the last 128 bytes and reads fixed-size fields. No external libraries, pure binary parsing.

C Binary Parsing fseek / fread Struct Mapping
View on GitHub ↗
PROJECT_07
🔢
Arbitrary Precision Calculator (APC)

A calculator that performs arithmetic on integers of unlimited size using Linked Lists — addition, subtraction and multiplication on numbers far beyond standard data type limits, built with clean modular code and shared headers.

C Linked Lists Dynamic Memory Modular Design GCC
